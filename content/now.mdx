## Building now

- **DBWhisper evals** — the natural-language-to-SQL agent is now measured on execution accuracy, not vibes: a golden-query harness (82% exact, 100% fail-closed) plus a scoped [Spider](https://yale-lily.github.io/spider) dev run (73%, 101/139). Numbers and method live on [Evals](/evals).
- **This site as a product** — turning the portfolio into a running notebook: [Notes](/notes), a public [eval registry](/evals), and the grounded, cited "Ask this site" assistant, all on the same $0 stack.
- **Keeping four products live** — [DBWhisper](/work/dbwhisper), [TradePulse](/work/tradepulse), [CrownWager](/work/crownwager), and [LLM Studio](/work/llm-studio) are deployed and maintained, not screenshots.

## Reading

- The **Model Context Protocol** specification — typed tool-use as a protocol, not per-agent glue.
- **Spider** (Yu et al., 2018) — the cross-domain text-to-SQL benchmark I'm measuring DBWhisper against.
